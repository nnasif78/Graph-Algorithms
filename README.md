# Graph Algorithms in C++

Simple C++ implementations of common graph algorithms.

## Algorithms

- `bellman.cpp` - Bellman-Ford shortest paths
- `dijkstra.cpp` - Dijkstra shortest paths
- `kruskal.cpp` - Kruskal minimum spanning tree
- `prims.cpp` - Prim minimum spanning tree

Compile and run one algorithm at a time:

```bash
g++ -std=c++17 dijkstra.cpp -o dijkstra
./dijkstra
```
